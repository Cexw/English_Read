# 人教版初中英语单词点读

静态单词表 demo，按新版人教版初中英语教材的单元顺序排列，共 5 册、2284 个词条。

## 运行

直接双击 `index.html` 即可。也可以在目录里起一个静态服务器：

```bash
python -m http.server 8123
```

然后打开 `http://127.0.0.1:8123`。

## 功能

- 切换七上、七下、八上、八下、九全五册，按 Starter Unit 和 Unit 顺序浏览。
- 搜索英文单词或中文释义，匹配结果按原教材单元分组。
- 点击单词打开详情，显示英式音标、词性释义、教材例句和拓展提示。
- 详情内可播放英式、美式发音，也可在列表里直接点行尾按钮试听。
- 点开详情会记为已读，进度保存在浏览器本地；可只看未读，也可分两步重置本册进度。
- 支持键盘操作：`/` 聚焦搜索，方向键切换单词或教材，`Esc` 关闭详情。

## 资源来源

| 内容 | 来源 | 说明 |
| --- | --- | --- |
| 词表、单元顺序、英式音标、释义、例句、用法提示 | GitHub 开源项目 [english-starry-sky](https://github.com/wenchester8-droid/english-starry-sky) 的 `public/atlas` 数据 | 按新版人教版（2024/2025）教材单词表整理，共 5 册 2284 词 |
| 英式、美式发音 | 有道词典公开接口 `https://dict.youdao.com/dictvoice?audio=<单词>&type=1`（英）/ `type=2`（美） | 播放时才请求，需要联网；接口失效时页面提供系统朗读 |
| 系统朗读兜底 | 浏览器 `window.speechSynthesis` | `en-GB` / `en-US`，音色由本机系统提供 |
| 页面字体 | 系统字体栈 | 不加载 Web 字体，不依赖 CDN |
| 图标 | 内联 SVG，站点图标 `favicon.svg` 为手绘 | 无第三方图标库 |

数据文件的字段是 `词条 w`、`uk` 音标、`senses` 释义、`ex` 例句、`tip` 用法、`page` 页码。
本站只做了重排：按单元分组、合并音标与释义、标出重点词和短语。

例句共 2284 条，其中 1719 条来自教材，477 条是词表项目补充的拓展例句，87 条标注为改编，1 条标注为 2025 年河南中考题。
详情弹窗末尾会写明每条例句的出处。

443 个短语、专有名词在原始数据里没有音标，页面显示“音标暂缺”，没有补造。
